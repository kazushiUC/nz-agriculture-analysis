## pandas_commands

=====
df = pd.read_excel(
    "DataFrame", sheet_name="sheet name", header=header number
)
-> load a DataFrame(xlsx format) only containing a specified sheet with a specified header
=====

=====
df.to_csv(
    "pathway",
    index=False
)
-> save the DataFrame as "xyz.csv" form in the identified pathway.
index=True   -> save the row index
index=False  -> do not save the row index
nothing      -> same as index=True
=====

=====
print(df.head(10))
-> show the first 10 rows and entire columns of the DataFrame.
=====

=====
print(df.shape)
-> show the number of rows and columns in a dataset like (rows, columns).
=====

=====
print(df.columns)
-> What are my variables/column names?
=====

=====
print(df.dtypes)
-> What type of data does each column contain?
=====

=====
print(df.isna())
-> to show wether each cell has a missing value or not.
=====

=====
print(df.isna().sum())
-> to show the number of missing values in each columns.
=====

=====
df.rename(
    columns={'original column name': 'ideal column name', 
             'original column name': 'ideal column name'}
)
-> to rename the specified original column name to an ideal column name

!!!What's the difference between including "inplace=True" and not.!!

=====

=====
df.drop(index=0)
-> to drop row 0 form DataFrame
=====

=====
df.drop(columns=[2004, 2005])
-> to drop 2004 column and 2005 column from DataFrame
=====

=====
df.melt(
    id_vars=["sector", "measure", "Units"],
    var_name="year",
    value_name="export_value"
)
-> to reshape a DataFrame from wide format to long format
-> "id_vars=[]" columns to keep fixed.
-> "var_name=''" names for the old column headers.
-> "value_name''" names for the old cell values.
